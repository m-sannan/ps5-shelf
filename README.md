# Crate

A PS5 disc library: poster grid, loans, sale prices, and a money page.

**Use it here: [ps5-shelf.vercel.app](https://ps5-shelf.vercel.app)**

On first visit, pick a local user. Tap **Sannan** for the sample shelf, or create your own. That profile lives in *your* browser only — it does not sync across phones.

- Browse, filter, or search the covers
- Tap a game to edit status, loans, art, and sale price
- **Money** is spend, recoveries, and transactions
- **Share** is a seller view of copies that are still around

## Run it on your machine

```bash
npm install
npm run dev
```

Then open [http://localhost:43127](http://localhost:43127). Most people should use the Vercel link above instead.
